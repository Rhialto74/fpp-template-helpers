Turning a pattern section into printable template pages

Two small add-ons do the fiddly work: one in Illustrator splits a big template onto letter-size sheets (Left and Right versions), and one in Word drops those sheets into the pattern, page by page, at exactly the right size.

Step 0 · Set up the helpers (once per computer)

Do this once. It puts the helpers in their own folder, adds the Word helper to Word, adds the Illustrator helper to Illustrator's menu, asks where your template sheets should go, and puts two icons on your desktop for later: Update FPP Helpers and Update Output Folder.

  1. Close Word and Illustrator if they're open.
  2. Download the installer (Install-FPP-Helpers.cmd). If your browser warns that this type of file can harm your device, choose Keep (in Edge: click … next to the warning, then Keep, then Keep anyway).
  3. Open your Downloads folder and double-click Install-FPP-Helpers. If a box says "The publisher could not be verified", click Run. If Windows shows a blue "Windows protected your PC" box, click More info, then Run anyway. You may see one, both or neither. A black window says it's downloading; leave it open – it closes by itself.
  4. It asks whether to put Make FPP Templates in Illustrator's File › Scripts menu. Click Yes, then Yes again when Windows asks for permission. This is needed only once. If you click No, you can still open the helper with File › Scripts › Other Script…, and the next update asks again.
  5. A window asks you to choose the folder for your template sheets. It starts at Documents › FPP-Template-Helpers › Pattern-Sheets; click OK to use that, or pick another folder first. The Illustrator helper saves sheets there every time, and the Word helper opens that folder when it asks for the sheets. To change it later, double-click Update Output Folder on your desktop.
  6. A message says the helpers are installed. You now have a folder Documents › FPP-Template-Helpers and two new icons on your desktop: Update FPP Helpers and Update Output Folder. You can delete Install-FPP-Helpers from Downloads. Tip: drag FPP-Template-Helpers onto "Quick access" in the left column of File Explorer so it's always one click away.
  7. Put your section files (the Group A–D files) in Documents › FPP-Template-Helpers, next to 1 Inch.ai. Keeping everything in one folder on the computer lets the Illustrator helper fill in the section name and find the 1-inch graphic by itself. Updates never change or remove your own files. If a section file lives in Adobe's cloud, save a computer copy first: open it in Illustrator, choose File › Save a Copy…, click Save on your computer if Illustrator offers it, go to Documents › FPP-Template-Helpers, keep the type as Adobe Illustrator (*.AI), Save, and click OK in the options window. Then open that copy for Part 1.

What you need

After Step 0, these are all in Documents › FPP-Template-Helpers. You don't need to open or understand the helper files.

FileWhat it is
MakeFPPTemplates.jsxThe Illustrator helper. Splits one section into numbered sheets, makes the Left and Right versions, adds the join marks, the sheet numbers and your 1-inch square, and saves them as pictures.
The Word helperAdds those pictures to the end of your pattern document, one per page, with a title and the exact print size. Set-up puts it inside Word for you, so you won't see it in this folder.
Update FPP Helpers.ps1, version.txt, Set up updates (run once)Used by the Update FPP Helpers icon. Leave them alone.
1 Inch.aiYour 1-inch scale square. Leave it in the folder with the helpers; the Illustrator helper finds it by itself.
Section filese.g. Group A-Right Image-LABELED.ai – one piecing section per file, with the patch labels typed in. Keep copies in Documents › FPP-Template-Helpers (not only in Adobe's cloud).
BRS Pattern Template.docxYour Word pattern template (not part of the helpers – use your own copy).
Left and Right, in one sentence: foundation paper piecing is sewn from the printed side, so the printed template is a mirror image of the finished front. The Group files show the Right half as it looks on the front, so the helper prints the Right templates mirrored and the Left templates as drawn – and turns your labels back around so they always read normally.

Part 1 · Make the sheets in Illustrator

Do this once for each section file (Group A, B, C, D). About a minute each.

Before the first file (once)

  1. Open your sheets folder (the one you chose in Step 0 – Pattern-Sheets unless you changed it). If it has folders from an earlier pattern or try, delete them so old pages don't end up in Word.

For each section file

  1. Open the section file from Documents › FPP-Template-Helpers (e.g. Group A-Right Image-LABELED.ai) – the copy on your computer, not the cloud version.
  2. Look around the artboard for anything that doesn't belong to this section – a stray line off to the side, a leftover shape. Click it and press Delete. Anything selected in the next step becomes part of the template. Optional tidy-up: Object › Path › Clean Up…, tick all three boxes, OK. This removes invisible leftovers.
  3. Press Ctrl + A to select everything. The lines turn highlighted with a box around them.
  4. Go to File › Scripts › Make FPP Templates. A window titled "Make FPP template sheets" appears. Not in the menu? Use File › Scripts › Other Script…, go to Documents › FPP-Template-Helpers and open MakeFPPTemplates.jsx – or run Update FPP Helpers and say Yes to the menu question.
  5. Check the window:
    • Section name – filled in from the file name (e.g. "Group A"). This is what prints on the pages. Change it if you like. If it's blank or odd, the file was opened from the cloud – type the name yourself, or use the computer copy.
    • Working area 7.25 × 8.75 and glue strip 0.5 – leave as they are.
    • "This artwork is the…" – leave RIGHT half selected for the Group files.
    • Make LEFT / Make RIGHT – leave both ticked.
    • Patch labels on the Right templates – "Same as Left" or "Add an R" (A-1 becomes A-1R). Your choice; use the same for every section.
    • 1-inch scale graphic – should already show the path to 1 Inch.ai. If it's empty, click Browse…, go to Documents › FPP-Template-Helpers and pick it once; it's remembered after that.
    • Save the sheets in – shows your sheets folder. Leave it. (Browse… picks another folder for this run only; to change the usual folder, use Update Output Folder on your desktop.)
    Click OK.
  6. If it asks whether to turn the section to save paper, either answer is fine. "Yes" uses fewer sheets with the shape slightly tilted on the paper.
  7. It saves the sheets in your sheets folder by itself, making two folders inside, e.g. "Group A - Left" and "Group A - Right".
  8. A message says how many sheets each side has. If it lists sheets with no room for the 1-inch graphic, that's normal for a sheet completely covered by the template; the square on the other sheets still checks the scale.
  9. A new, untitled document is open with all the sheets. You can close it without saving – the pictures are already saved. Your original file is never changed.
Red error box? Take a screenshot of it (it names a "Line" number) and send it to whoever looks after these helpers. Close the untitled document without saving and try again once it's fixed.

Part 2 · Word

Nothing to do: Step 0 added the Word helper to Word, and Word loads it by itself every time it starts. You'll find it under View › Macros as AddTemplateSheets.

If Word says macros are disabled: File › Options › Trust Center › Trust Center Settings… › Macro Settings, choose "Disable VBA macros with notification" (or similar wording), OK, and restart Word.
Does the Macros list show the helper twice, e.g. as Normal.FPPSheets.AddTemplateSheets and FPPHelpers.FPPSheets.AddTemplateSheets? The "Normal" one is an old copy from before the set-up did this for you. Update FPP Helpers offers to remove it (click Yes; Word must be closed). To remove it by hand instead: Developer › Visual Basic, under Normal › Modules right-click FPPSheets, choose Remove FPPSheets (answer No to exporting), and close that window.

Part 3 · Put the sheets into the pattern

  1. Open BRS Pattern Template.docx and straight away use File › Save As to save it under the pattern's name (e.g. "Deco Pattern.docx"). This keeps the template clean.
  2. Click the View tab, then Macros (far right) › View Macros.
  3. Click AddTemplateSheets in the list, then Run.
  4. The folder window opens at your sheets folder. Click OK to add everything in it. You can also pick just one folder, such as "Group A - Left", to add only that.
  5. It asks "Add N page(s) to the end of …?" – click OK. It takes a moment. Each sheet gets its own page with a teal title such as "Group A - Left Template (Sheet 2 of 5)", a short print note, and the sheet at its exact size. Every section starts with its assembly map.
  6. Scroll through and check a few pages, then save.
Page order: sections are added in folder-name order (Group A, B, C, D), Left before Right. To change it, rename the folders inside your sheets folder with a number in front (e.g. "1 Group C - Left"). Titles on the pages don't change.
Ran it twice by accident? Close the document without saving and start again from your last saved copy.

Part 4 · Print at true size

  1. File › Print. Paper size: Letter.
  2. The last setting (usually "1 Page Per Sheet") › Scale to Paper Size › No Scaling.
  3. Click Printer Properties and turn off anything like "Fit to page", "Shrink" or "Scale" (or set it to 100%).
  4. Print one sheet first and measure the 1-inch square with a ruler. If it's exactly 1 inch, print the rest.

Getting updates

  1. Save your work and close Word.
  2. Double-click Update FPP Helpers on your desktop.
  3. A message says either that you already have the newest version, or which version was installed. That's it – the next time you open Illustrator and Word they use the new version. If it asks you to close Word, do that and click OK. After a new Illustrator version is installed it may ask again about the File › Scripts menu – click Yes. Your section files, your sheets folder and your 1 Inch.ai are never changed.

If something goes wrong

What you seeWhat to do
The assembly map shape has an odd spike, or there are more sheets than expectedSomething stray was selected. Close the untitled document, delete the stray item in the section file (or run Clean Up), select all again and rerun.
Section name is blank or strange, or the 1-inch path is emptyThe file was opened from Adobe's cloud. Type the name in yourself and use Browse for 1 Inch.ai – or better, save a computer copy as in Step 0 and use that.
Labels read backwards on one sideThose labels were turned into outlines. Retype them with the Type tool as normal text and rerun.
"AddTemplateSheets" isn't in the Macros listClose Word, double-click Update FPP Helpers on your desktop, then open Word again. If it's still missing, check the macro setting in Part 2.
"No sheets were found there"You picked the wrong folder. Pick your sheets folder, or one of the "… - Left/Right" folders inside it.
You want the sheets saved somewhere elseDouble-click Update Output Folder on your desktop and choose the new folder. Both helpers use it from then on.
A warning that pictures were stretchedA sheet picture was edited or swapped. Rerun the Illustrator helper for that section and add the pages again.
Printed 1-inch square isn't 1 inchSomething is scaling the print. Check Part 4, especially Printer Properties.
A red error box in Illustrator or WordScreenshot it and send it on. Nothing in your original files is changed.
